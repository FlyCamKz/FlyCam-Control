# Программа верификации FlyCam AeroScope/AgroScope

Документ задаёт воспроизводимый минимум до обращения в испытательную
лабораторию. Итоговую программу и критерии принимает заказчик совместно с
аккредитованной организацией.

## Автоматизированные проверки

| ID | Проверка | Критерий |
|---|---|---|
| SW-BUILD-01 | Windows x64 Release и NSIS | установщик, QGC, диспетчер и видеоаналитика созданы |
| SW-DISP-01 | API телеметрии нескольких БПЛА | ID 1 и 2 хранятся независимо |
| SW-DISP-02 | Валидация событий/обнаружений | ошибочные ID, confidence и bbox отклоняются |
| SEC-AUTH-01 | Раздельные ключи ролей | ingest не читает, viewer не пишет, operator меняет задания |
| SEC-AUD-01 | Отказ аутентификации | запись аудита не содержит ключа |
| SEC-NET-01 | Внешний bind без защиты | запуск отклоняется |
| SEC-TLS-01 | TLS 1.2+ | устаревший протокол не устанавливает соединение |
| SEC-MTLS-01 | Обязательный клиентский сертификат | неизвестный/отозванный сертификат отклоняется |
| VID-CORE-01 | Геометрия bbox после letterbox | координаты остаются в диапазоне 0..1 |
| VID-PRIV-01 | Секрет RTSP | пароль и query-параметры отсутствуют в журнале/событии |
| VID-TRACE-01 | Прослеживаемость модели | каждое событие содержит SHA-256 модели |

## Стендовые проверки

| ID | Сценарий | Измеряемый результат |
|---|---|---|
| HW-GPS-01 | GPS подключён к GPS2 | спутники, fix, HDOP/VDOP после холодного старта |
| HW-LINK-01 | USB и RFD900/SiK отдельно | потери, задержка, восстановление после обрыва |
| HW-FLEET-01 | 2–5 БПЛА с уникальными `MAV_SYS_ID` | отсутствие смешивания телеметрии и команд |
| HW-CARGO-01 | S3001 без пропеллеров | направление, ток, пределы PWM, failsafe, концевик |
| VID-CAM-01 | Выбранная камера RTSP/USB | 30 минут без разрыва и утечки памяти |
| VID-LAT-01 | Инференс на целевом ПК | p50/p95 задержки и загрузка CPU/GPU |
| VID-ACC-01 | Размеченный набор сцен | precision/recall/F1 по людям и каждому типу транспорта |
| SEC-KEY-01 | Компрометация/ротация ключа | старый ключ отклонён, новый принят, событие записано |
| SEC-LOG-01 | Заполнение диска/сбой SQLite | безопасный отказ и диагностируемое состояние |

## Лётная приёмка

Лётные тесты выполняются после стенда, проверки RTL/геозоны/батарейного
failsafe в SITL и утверждения ответственного за безопасность. Проверяются
маршрут с одним БПЛА, параллельная телеметрия двух БПЛА, потеря одного канала,
возврат связи и корректность привязки обнаружений к ID/координатам. Команда
открытия отсека проверяется отдельно и не должна поступать с диспетчерского API.

## Артефакты доказательной базы

- SHA коммита и идентификатор CI-запуска;
- хэши установщика, исполняемых файлов и ONNX-модели;
- журнал автоматических тестов;
- конфигурация PX4 и уникальные `MAV_SYS_ID`;
- схема сети, сертификатов и ролей;
- отчёты статического анализа, пентеста и нагрузочного теста;
- видео/фото стенда и подписанные протоколы наземных/лётных испытаний;
- перечень отклонений с ответственными и сроками.
